3. **Role Escalation Vulnerability:** `setUserRole` in `src/actions/admin.ts` uses `requireModerator()` instead of `requireAdmin()`. Any moderator can elevate accounts to admin.
4. **Admin API Route Inconsistency:** `src/app/api/admin/autopilot/route.ts` allows moderators (`isAdmin()` checks for admin/mod), but the underlying server actions require admin.
5. **CSP `'unsafe-inline'` and `'unsafe-eval'` Allowed:** `next.config.mjs` weakens XSS protection significantly.
6. **Audit Log Insert Policy Too Permissive:** `20260605000002_rls_policies.sql` allows any unauthenticated user to insert audit logs, enabling log pollution.

### 🟡 P2 — MEDIUM

**13/13 model bunu söylüyor.** Sıfır rapor, sıfır kullanıcı, sıfır ülke = platform ölü görünüyor. Ziyaretçiler 5 saniye içinde çıkıyor. Çözüm: 50 gerçek vaka ile tohum veri.

**13/13 model bunu söylüyor.** Grok pasaport skandalı dünyanın en güçlü founding myth'lerinden biri — ama sitede hiç görünmüyor. Bu tek başına -25 puan.

### #3 SORUN: Login Wall Rapor Öncesi

**12/13 model bunu söylüyor.** Rapor göndermek için önce kayıt istemek cold-start'ta dönüşümü %60-80 düşürüyor. Çözüm: Anonim raporlama, sonradan kayıt.

### #4 SORUN: Zero-Data State Mesajı

**11/13 model bunu söylüyor.** "No incidents reported yet. Be the first." cümlesi sosyal kanıt çöküşü yaratıyor. "İlk sen ol" demek "kimse kullanmıyor" demek.

### #5 SORUN: Homepage Copy Duygusuz

**13/13 model bunu söylüyor.** Fear → Empathy → Solution → Action yayı yok. "Trust infrastructure for AI" soğuk, teknik, harekete geçirici değil.

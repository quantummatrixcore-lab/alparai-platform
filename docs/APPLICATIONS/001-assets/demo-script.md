---

### Step 1: Public AI Incident Registry (60 Seconds)

- **URL:** `https://alparai.com/en/incidents`
- **Action:** Show the live incident feed. Filter by severity or category.
- **Talking Point:** _"Here is the live registry tracking 400+ AI incidents globally. Every incident includes source verification, structured metadata, and automated PII masking."_

- **URL:** `https://alparai.com/en/benchmark`
- **Action:** Open a model rating breakdown (e.g. GPT-4o vs Claude 3.5 Sonnet).

### Step 3: Enterprise B2B Risk API (60 Seconds)

### Step 4: Real-time Browser Extension (60 Seconds)

- **Action:** Open ChatGPT or Claude.ai in Chrome with the ALPAR AI extension enabled.
